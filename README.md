# Kuliah Sebulan Jadi Pengusaha (PPQ)

## Cara menjalankan
1. VS Code: File > Open Folder > pilih folder `ibu_zakiah`.
2. Pasang ekstensi **Live Server**, lalu klik kanan `index.html` > **Open with Live Server**.

## Menambah video MP4 (PALING MUDAH)
1. Ganti nama file video menjadi `video1.mp4` (berikutnya `video2.mp4`, `video3.mp4`, ...).
2. Taruh di folder `videos/`.
3. Refresh browser (Ctrl+F5). Video muncul otomatis di Galeri Video.

## Reel Instagram
Sudah ada 2 reel di `videos/videos.js`. Tambah baris baru dengan format yang sama untuk menambah reel.
